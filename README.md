# DJ Dual Deck

Android DJ dual-deck player with crossfader, independent decks, equalizer and 7 visual skins.

The Android application loads its bundled local HTML console in a WebView. Build APK using GitHub Actions (`Actions → Build Android APK`), download the `DJ-Dual-Deck-APK` artifact. A `v*` tag can publish an APK under GitHub Releases.

Package: `com.anderza.djdualdeck`. App label: **DJ Dual Deck**.

This is a preview-stage Android app. Verify music library selection and audio behavior on your phone before treating it as production-ready.
